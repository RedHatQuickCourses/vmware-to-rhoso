== Enable Automation Hub

In this environment, the Automation Hub is disabled by default. We need to enable it to be able to build the execution environment and push it to the AAP's internal registry.

[source,bash,role=execute]
----
oc patch ansibleautomationplatform aap -n aap --type=merge -p '
spec:
  hub:
    disabled: false
    storage_type: file
    file_storage_class: nfs
    file_storage_capacity: 10Gi
'
----
